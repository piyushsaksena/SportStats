METHOD 2: FULL-STACK FASTAPI BACKEND MODE (FOR DEVELOPERS & EXAMINERS)
--------------------------------------------------------------------------------
If you want to run the asynchronous Python FastAPI REST backend:

1. Double-click "run_dashboard.bat" and press [2].
   OR in PowerShell / Terminal run:
      pip install -r requirements.txt
      python -m uvicorn sportstats.api.main:app --app-dir backend/src --host 127.0.0.1 --port 8000 --reload

2. Open your browser and navigate to:
   - Web Application:   http://localhost:8000/
   - Interactive Swagger API Docs: http://localhost:8000/docs
   - System Health Heartbeat:      http://localhost:8000/health
